# Triton Ocean Systems investor deck

`index.html` displays the revised 12-page `Triton_PreSeed_Deck_v3.pdf` and links to it for download. Earlier PDFs are retained for history.

The v3 narrative focuses on a proposed South Florida beachfront resort sargassum cleanup use case. Targets and pricing are explicitly assumptions; no new traction is claimed.

## Editable source

Install Python 3 and the dependencies in `requirements.txt`, then run `python build_deck.py`. The build uses Arial on Windows and Helvetica elsewhere, preserves the original navy/cyan identity, and produces selectable PDF text. The source observation-surface artwork lives in `assets/observation-surfaces.png` and is extracted from the original v2 deck.

Read `CLAIMS_AND_ASSUMPTIONS.md` before investor circulation. It includes source links, arithmetic, unsupported metrics, falsification tests and evidence gaps. A finished deck is not validation of the investment assumptions.
